Automata - Experiments with Neural Particle Automata
====================================================
Some experiments with generalizing **neural cellular automata** (**NCA**) to dynamic point clouds using graph convolutional networks. The models are trained to parameterize a nonlinear recurrence relation that, provided an initial "seed" state, converges in finite time to a unique target state via local message propagation.
